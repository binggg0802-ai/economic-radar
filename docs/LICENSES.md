政府資料開放平臺上，證交所的三個資料集都標示「政府資料開放授權條款第 1 版」、免費、每日更新，API 文件都指向 openapi.twse.com.tw：

依該授權條款，原則上可商業利用，但須標示來源。
仍標「待確認」的原因有兩點：

- 證交所網站使用條款與「交易資訊使用管理辦法」是否另外拘束這批盤後資料，沒有書面說明。
- 再散布（例如把整份歷史資料提供給第三方下載）是否在許可範圍內，也沒有書面說明。

## 證交所：為什麼仍是「待確認」

1. **網站使用條款**：未經證交所同意，禁止以自動化程式、爬蟲等方式下載網站資料（twse.com.tw/zh/terms/use.html）。
   - 本系統只呼叫 `openapi.twse.com.tw` 的公開 API，不抓 www.twse.com.tw 網頁。
   - OpenAPI 本身是否屬於「經證交所同意之方式」、能否用於商業 App，網站上沒有找到明文。
2. **交易資訊使用管理辦法**：即時與延遲（≥20 分鐘）交易資訊須簽約付費。
   - 例如以網站或 App 傳輸、具自動更新功能者，0～5,000 戶每月新台幣 10 萬元。
   - 本系統只使用**盤後收盤資料**，不顯示即時或延遲行情。
   - 盤後資料用於商業 App 是否也需簽約，**待確認**。
3. 證交所特刊說明：交易資訊屬證交所所有，加值處理後的內容由使用者自負正確性責任。

**建議**：上架前以書面（Email 或公文）詢問證交所資訊服務窗口。詢問時說明：只顯示盤後收盤指數、每日一次、標示來源、不提供即時或延遲行情。
在取得回覆前，前端會依授權欄位顯示「授權：待確認」。

## 金鑰與安全

- 目前接入與規劃中的四個來源都**不需要 API 金鑰**。
- 管線不讀任何 Secret。Workflow 只用 GitHub 自動提供的 `GITHUB_TOKEN`（contents: write），權限只限本 Repository。
- 若日後改用 BLS API v2（需金鑰），金鑰只放 GitHub Actions Secrets，由 Actions 在伺服器端使用。前端與公開檔案中不會出現金鑰。
- App／後端原始碼含 `app/.env`，**不會**放進公開 Repository。放進 `main` 前要先做秘密掃描。
